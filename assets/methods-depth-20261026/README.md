# 方法与算法深化的教学材料

对应[系统学习指南](../../wiki/方法与算法系统学习指南.md)。三套runner分别提供26个基础/统计/序列、22个群体/GS/变异、22个测量/组学人工算例；数学桥接页另有一个NumPy短例。这里保存实际输出、代码与正文一致性清单、环境和原绘图。

所有输入为脚本内置的人工数字或字符串，没有真实个体资料；不下载生产数据。例子用于核对计算步骤，不能当作已运行REML、SKAT、祖源软件、真实组装或湿实验。原有已验证专业案例保持各自来源与验证范围。

`foundations-cases.json`记录基础runner与方法页Python块的对应及代码SHA。`method-pages.json`记录70篇方法本轮前后的长度、SHA与case命令；长度仅用于审计改动规模，不作为知识质量证明。公式和符号是通常数学记号，正文与人工例独立撰写。

两张图由[绘图脚本](../../examples/plot_methods_foundations.py)用与方法页相同输入生成。`global-alignment.png`的箭头是回溯方向，`pca-projection.png`按第一方向分量为正展示同一PCA轴；轴整体反号不改变模型。图已视觉检查。

完整来源比较、双代理纠错、测试和未验证范围见[维护记录](../../maintenance/methods-depth-2026-10-26.md)。
