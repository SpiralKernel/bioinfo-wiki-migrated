# 方法与算法系统学习指南

> 更新：2026-10-26；状态：可用；验证范围：2026-10-26结构与内部链接核对；微型Python练习已执行；专业软件范围以各案例声明为准。

这里按“问题→数学对象→计算→检查→生物解释”组织方法学习。读者可以先走共同基础，再选群体/GWAS/GS、变异检测或组学分支。每个方法页提供直觉、模型或步骤、数值例、可执行计算、参数影响、排错与自测；工具安装和完整真实任务通过对应工作流承接。

## 先选一个可以完成的小目标

| 你的起点 | 先做什么 | 完成标志 |
|---|---|---|
| 只会读表，编程刚开始 | [R与Python生信编程入门路线](https://github.com/SpiralKernel/bioinfo-wiki/wiki/R%E4%B8%8EPython%E7%94%9F%E4%BF%A1%E7%BC%96%E7%A8%8B%E5%85%A5%E9%97%A8%E8%B7%AF%E7%BA%BF)→复杂度/查找 | 能说清一行是谁、缺失怎样表示，运行一次计数 |
| 想理解序列比对 | 动态规划→局部比对→BLAST→索引 | 能填小矩阵、回溯、解释漏命中 |
| 熟悉群体分析/GWAS | PCA→混杂→LD/FST→混合模型 | 能解释矩阵、独立单位、假设与诊断 |
| 准备做GS | 验证设计→岭/GBLUP→REML→贝叶斯/单步 | 能区分预测目标、惩罚尺度与训练外验证 |
| 想理解RNA/单细胞 | 检验/GLM→计数模型→设计/图/批次 | 能区分供体与细胞、效应与校正P |
| 面对一份变异结果 | 似然→证据→分型/匹配→真值区域 | 能保留未知，说明TP分母与可检出范围 |

表中缩略链接的完整条目列在下方。第一次学习可每天完成一篇，先算小例，再进入工作流；不要求先读完全部70篇。

## 怎样跑例子并知道自己做对了

先[下载仓库ZIP](https://github.com/SpiralKernel/bioinfo-wiki/archive/refs/heads/main.zip)并进入含README与examples的项目根目录，具体步骤见[R与Python路径文件与项目组织](https://github.com/SpiralKernel/bioinfo-wiki/wiki/R%E4%B8%8EPython%E8%B7%AF%E5%BE%84%E6%96%87%E4%BB%B6%E4%B8%8E%E9%A1%B9%E7%9B%AE%E7%BB%84%E7%BB%87)。基础runner含26个case，其中部分依赖NumPy/SciPy；另两个runner各含22个只用Python标准库的case。不需要为了运行后两者先安装专业组学/遗传软件。

**首次准备完整项目环境**时，macOS/Linux终端执行：

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements-teaching.txt
.venv/bin/python examples/methods_foundations_demo.py --list
.venv/bin/python examples/methods_foundations_demo.py --case pca --output examples/output/methods-pca
```

若项目已有正确的`.venv`，跳过创建环境那一行，继续用同一解释器检查/安装所需依赖。不要因每读一篇就重新创建环境。Windows PowerShell的对应步骤为：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-teaching.txt
.\.venv\Scripts\python.exe examples/methods_foundations_demo.py --list
.\.venv\Scripts\python.exe examples/methods_foundations_demo.py --case pca --output examples/output/methods-pca
```

若Windows仅有`py`，仅把创建环境那行的`python`换成`py`，后续仍用环境解释器。以上不依赖激活环境；也不要把`python ...`终端命令粘入Python或R控制台。

**只想先跑标准库例子**时，已有Python 3.10+即可，在项目根目录的macOS/Linux终端执行：

```bash
python3 examples/methods_genetics_demo.py --list
python3 examples/methods_genetics_demo.py --case ld --output examples/output/methods-genetics-ld
python3 examples/methods_omics_demo.py --list
python3 examples/methods_omics_demo.py --case rna --output examples/output/methods-omics-rna
```

Windows将这组命令开头的`python3`换成可用的`python`或`py`；若已使用项目环境，也可统一换成上述`.venv`解释器路径。三个runner的case名称各自独立，同一主题的参数名不要互相猜用；`--help`和`--list`只查看说明，不生成结果。

| runner | 本例输出位置与检查 |
|---|---|
| methods_foundations_demo.py | methods-pca/summary.json：results列表中case=pca，stdout含解释率[1,0]和重建误差0 |
| methods_genetics_demo.py | methods-genetics-ld/summary.json：cases.ld.r2=0.25 |
| methods_omics_demo.py | methods-omics-rna/summary.json：cases.rna.normalized=[20,20,80,80]，log2倍数为2 |

表中目录均在examples/output下，JSON结构因runner而异。genetics未传`--output`时仅打印；omics未传`--output`时写入对应case的默认目录且必须选择`--case`；foundations不选择case会运行全部26例并使用其默认目录。初学优先使用上面的显式单case和输出命令。输入均为人工数字/固定项目小计算，不联网下载生产数据。

输出目录已有结果时会拒绝覆盖；再次练习请用`--output`指定新目录。查看summary.json时核对case、输入、单位和检查点。代码成功后再完成页末自测：换输入/参数先预测结果，再运行；只背默认输出还不算掌握方法。

| 可核对任务 | 算例结果 | 能说明什么 |
|---|---|---|
| 全局比对ACGT与AGT | 匹配2/错配−1/缺口−2下得4分 | 实现与所设评分一致 |
| 三点PCA | PC1解释全部方差，重建误差约0 | 秩一矩阵分解与重建 |
| 混杂反例 | 总体斜率负，调整组别后斜率1 | 条件与总体关系可不同 |
| 两状态HMM | 最佳路径[0,0,1]联合概率0.05184 | 最优路径不同于总似然0.10452 |
| FM精确搜索ana | banana中0基起点1、3 | 区间计数与定位一致 |

这些算例验证数学与代码的一致性；真实样本的统计与生物有效性还需对应工作流、设计和独立证据。已经实跑的专业案例会写明版本和输入，未跑的模板也会明确标注。

## 学完一篇后的验收方式

用自己的话回答五句：它解决什么问题；数据与参数各是谁；一小步怎样算；哪个输出能检查错误；在哪种条件下结论失效。然后完成一个反例，例如改变距离尺度、把配对打乱、让种子消失或调整转移概率。若答不出，回到相关概念与手算段，不急着增加新软件。

本轮组织参考[Galaxy Training Network的教程结构](https://training.galaxyproject.org/training-material/topics/contributing/tutorials/create-new-tutorial/tutorial.html)、[Bioinformatics Workbook的问题与练习设计](https://bioinformaticsworkbook.org/about.html)、[SeqAn的目标/前置/算例/作业](https://seqan.readthedocs.io/en/main/Tutorial/Algorithms/Alignment/PairwiseSequenceAlignment.html)和[Truvari Wiki的参数与匹配解释](https://github.com/ACEnglish/truvari/wiki/bench)。正文与数值例重新撰写；专业事实分别引用原论文和官方资料，未复制其他项目的教程正文。
