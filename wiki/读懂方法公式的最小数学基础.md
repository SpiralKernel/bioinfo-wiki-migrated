# 读懂方法公式的最小数学基础

> 更新：2026-10-26；状态：可用；验证范围：2026-10-26教材/官方资料核对；NumPy微型计算已执行；不是完整数学课程。

公式是把计算规则压缩写下来的语言。第一次读方法页时，先给每个符号找到“它对应表中的什么”，再看怎样运算。本页只讲阅读现有方法最常用的符号，用一张三样本表贯穿解释；复杂推导可按需要回查课程，不要求一次学完线性代数。

## 先规定一张表的方向

| 样本i | 测量x | 响应y |
|---|---:|---:|
| 1 | 1 | 3 |
| 2 | 2 | 5 |
| 3 | 3 | 7 |

这里n=3表示样本数，x、y各有三个值。向量是一列按顺序排列的数；同一向量中顺序变化会改变与另一列的对应。小写xi表示第i个样本的x，大写X通常表示二维矩阵。字母大小写并非全领域统一，须看每篇定义。

## 求和、均值和平方为什么常见

$\sum_{i=1}^n x_i$就是x1+x2+…+xn，本表为6；$\bar x=\sum_i x_i/n=2$。中心化后的x−x̄为[−1,0,1]，平方和为2。平方使正负偏差不会互相抵消，并更重视大偏差。

样本方差常写$s^2=\sum_i(x_i-\bar x)^2/(n-1)$，本表为1；标准差s=1，与x同单位，方差单位是原单位的平方。标准误衡量估计量的抽样波动，不等于个体数据标准差；详见[抽样分布中心极限定理与标准误](https://github.com/SpiralKernel/bioinfo-wiki/wiki/%E6%8A%BD%E6%A0%B7%E5%88%86%E5%B8%83%E4%B8%AD%E5%BF%83%E6%9E%81%E9%99%90%E5%AE%9A%E7%90%86%E4%B8%8E%E6%A0%87%E5%87%86%E8%AF%AF)。

帽子$\hat\beta$常指从数据估计出的参数，上横线常指平均，星号可能表示新样本，t可能表示时间也可能表示迭代。它们都是约定，不能脱离上下文猜。

## 矩阵乘法是在同时算许多加权和

线性模型y=Xβ+e中，X为n行p列设计矩阵，β为p维参数，e为n维误差。若包含截距，X第一列全1；本表取X行分别(1,1)、(1,2)、(1,3)，β=(1,2)，则Xβ行分别为1+2×1=3、1+2×2=5、1+2×3=7。

矩阵相乘要求内维一致：(n×p)乘(p×1)得到(n×1)。Python/NumPy的`@`表示矩阵乘法，`*`通常是逐元素乘；二者混淆可能悄悄得到错误结果。转置Xᵀ把行列交换，形状变p×n；XᵀX因此为p×p。矩阵逆X⁻¹通常只对可逆方阵定义，不是每个元素取倒数。

求Xβ=y通常应使用求解或最小二乘分解，不直接手写逆矩阵。列秩表示独立列数；重复或线性组合列使参数无法分别识别。例如同时加入截距和两组完整0/1指示列，若两指示相加恰为1，就有冗余。相关背景可查[MIT线性代数课程](https://ocw.mit.edu/courses/18-06-linear-algebra-spring-2010/)。

## 动手核对维度、预测与对数

先在项目根目录按[R包Python包与可复现环境](https://github.com/SpiralKernel/bioinfo-wiki/wiki/R%E5%8C%85Python%E5%8C%85%E4%B8%8E%E5%8F%AF%E5%A4%8D%E7%8E%B0%E7%8E%AF%E5%A2%83)准备NumPy，在Python中执行：

```python
import numpy as np
from math import log, log2, exp
x = np.array([1.,2.,3.])
y = np.array([3.,5.,7.])
X = np.column_stack([np.ones(3),x])
beta = np.linalg.lstsq(X,y,rcond=None)[0]
print('shapes', X.shape, X.T.shape, (X.T@X).shape)
print('coefficients', np.round(beta,6))
print('prediction', np.round(X@beta,6))
print('variance', x.var(ddof=1))
print('logs', log2(8), round(log(exp(2)),6))
assert np.allclose(beta,[1,2]) and np.allclose(X@beta,y)
assert X.shape==(3,2) and x.var(ddof=1)==1
```

检查点为(3,2)、(2,3)、(2,2)，参数[1,2]，预测[3,5,7]，方差1、log₂8=3。这个完全线性小表只有演算作用，不据此报告真实模型的P或预测性能。代码只打印结果，不写文件。

## 对数、指数与比例

对数log_b(a)=c表示bᶜ=a。生信常见log₂用于倍数变化：log₂FC=1表示2倍，−1表示一半，0表示1倍而非“没有表达”。自然对数ln以e为底，许多文献简写log；exp是其逆运算。log(a×b)=log a+log b，使似然连乘能转成求和，但要求a、b为正。

对数0未定义；为了画图加伪计数会改变低值附近的比例，不能把`log2(count+1)`与真正的条件均值log₂FC当成同一个量。Phred等负对数尺度还有单独定义与单位，见[测序深度覆盖度与质量分数](https://github.com/SpiralKernel/bioinfo-wiki/wiki/%E6%B5%8B%E5%BA%8F%E6%B7%B1%E5%BA%A6%E8%A6%86%E7%9B%96%E5%BA%A6%E4%B8%8E%E8%B4%A8%E9%87%8F%E5%88%86%E6%95%B0)。

## 概率与模型的符号

| 符号 | 可以怎样读 | 需防止的误读 |
|---|---|---|
| P(A\|B) | 已知B条件下A的概率 | 不等于P(B\|A) |
| E(Y\|X) | 给定X时Y的条件平均 | 不表示每个个体都等于该值 |
| Var(Y) | Y的变异尺度 | 不等于估计均值的标准误 |
| Y∼N(μ,σ²) | 指定正态分布及均值/方差 | 不是说数据都落在μ±σ |
| argmaxθ f(θ) | 使f最大的参数位置 | max给函数值，argmax给位置 |
| ∝ | 与某量成比例 | 归一化常数可能尚未写出 |
| I | 单位矩阵或指示函数 | 看上下文和维度 |

P(A\|B)中的竖线是条件符号；绝对值|x|、矩阵行列式|V|也是竖线，但含义不同。REML中的log|V|涉及协方差矩阵整体尺度，初学时先把V和模型认清，再进入该页推导。范数‖v‖通常表达向量大小，PCA与岭回归中的平方范数就是平方和。

## 导数与特征分解先抓住用途

导数衡量参数小改动时函数怎么变化；多参数偏导组成梯度，见[梯度下降与数值优化](https://github.com/SpiralKernel/bioinfo-wiki/wiki/%E6%A2%AF%E5%BA%A6%E4%B8%8B%E9%99%8D%E4%B8%8E%E6%95%B0%E5%80%BC%E4%BC%98%E5%8C%96)。特征向量满足Kv=λv，表示沿该方向作用矩阵只改变比例；PCA用相应方向总结变异。SVD可处理更一般的矩形矩阵，见[PCA原理与实现](https://github.com/SpiralKernel/bioinfo-wiki/wiki/PCA%E5%8E%9F%E7%90%86%E4%B8%8E%E5%AE%9E%E7%8E%B0)，不要把SVD与PCA当作全部同义。
