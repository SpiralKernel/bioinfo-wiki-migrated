# 相关回归与混杂

> 更新：2026-10-26；状态：可用；验证范围：2026-10-26核对原始与官方资料；本页Python微型计算已执行；人工数据不代表专业软件或真实研究性能。

相关描述两变量怎样共同变化，回归描述响应条件均值如何随预测变量改变；两者都不自动证明因果。混杂可使总体相关与组内关系方向相反。读完应能手算回归斜率、解释协变量调整，并用一个反例识别“整体相关”的陷阱。

前置为[随机变量期望方差与协方差](https://github.com/SpiralKernel/bioinfo-wiki/wiki/%E9%9A%8F%E6%9C%BA%E5%8F%98%E9%87%8F%E6%9C%9F%E6%9C%9B%E6%96%B9%E5%B7%AE%E4%B8%8E%E5%8D%8F%E6%96%B9%E5%B7%AE)与[线性模型与混合模型](https://github.com/SpiralKernel/bioinfo-wiki/wiki/%E7%BA%BF%E6%80%A7%E6%A8%A1%E5%9E%8B%E4%B8%8E%E6%B7%B7%E5%90%88%E6%A8%A1%E5%9E%8B)。数据顺序、独立单位和时间先后需要在计算前明确。

## Pearson、Spearman与回归斜率

Pearson相关$r=\sum_i(x_i-\bar x)(y_i-\bar y)/\sqrt{\sum_i(x_i-\bar x)^2\sum_i(y_i-\bar y)^2}$，无单位，主要描述线性关系。Spearman对秩作相关，关注单调关系；并列取平均秩等规则需明确。r=0不代表完全独立，非线性关系可能很强而线性相关为0。

简单最小二乘$y=\beta_0+\beta_1x+\epsilon$的斜率$\hat\beta_1=S_{xy}/S_{xx}$，截距ȳ−β̂1x̄。斜率保留y/x单位；同一r可以来自截然不同的尺度。残差最小化、参数区间和P又需要独立性、误差等条件，接口示例见[SciPy linregress文档](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.linregress.html)。

## 一个“组内正、整体负”的例子

第一组x=[1,2,3]、y=[11,12,13]；第二组x=[8,9,10]、y=[1,2,3]。每组内部x每增加1，y增加1，斜率都为1；但第二组整体x高而y低，混在一起后的斜率约−1.3032。组别是此构造里应纳入的结构，直接总体相关掩盖组内关系。

> 本页例子在项目根目录的Python中运行；标准库例子无需安装包，含NumPy/SciPy的例子先按[R包Python包与可复现环境](https://github.com/SpiralKernel/bioinfo-wiki/wiki/R%E5%8C%85Python%E5%8C%85%E4%B8%8E%E5%8F%AF%E5%A4%8D%E7%8E%B0%E7%8E%AF%E5%A2%83)建立项目环境。Windows命令使用`python`，macOS/Linux可使用`python3`；代码块可复制进该环境的Python交互会话，或保存为项目根目录下的临时脚本再用该环境解释器运行；不要保存到examples目录或任意外部目录后假定项目导入路径仍相同。除特别说明外，只向屏幕输出，不写文件。

```python
import numpy as np
x = np.array([1.,2.,3.,8.,9.,10.])
y = np.array([11.,12.,13.,1.,2.,3.])
group = np.array([0.,0.,0.,1.,1.,1.])
simple = np.linalg.lstsq(np.column_stack([np.ones(6),x]),y,rcond=None)[0]
adjusted = np.linalg.lstsq(np.column_stack([np.ones(6),x,group]),y,rcond=None)[0]
print('pooled_slope',round(float(simple[1]),6))
print('adjusted_intercept_x_group',np.round(adjusted,6))
assert simple[1] < 0 and np.isclose(adjusted[1],1)
```

检查点：总体斜率为负，调整模型系数[10,1,−17]。这是人工完全线性数据，没有用零残差计算可信P或推断真实因果；其作用是展示“总体与条件关系不同”完全可能。

## 调整协变量为什么也需要因果考虑

多元回归$y=X\beta+\epsilon$在模型内比较协变量相同条件下的均值差。如果混杂因素同时影响暴露和结果，适当调整可能改善估计；但测量误差、未观测混杂与模型错设仍可残留。中介位于作用路径上，调整后目标可能变成直接效应；碰撞变量由两方共同影响，调整它反而可能引入偏差。不能“能拿到的变量全部加上”就称控制完混杂。

组学中的年龄、批次、祖源和家系既可能是真实结构，也可能与分组完全重合。若所有病例在批次A、对照在批次B，单靠回归通常无法识别批次与病例效应，见[组学批次校正与信号保留](https://github.com/SpiralKernel/bioinfo-wiki/wiki/%E7%BB%84%E5%AD%A6%E6%89%B9%E6%AC%A1%E6%A0%A1%E6%AD%A3%E4%B8%8E%E4%BF%A1%E5%8F%B7%E4%BF%9D%E7%95%99)。设计阶段平衡与重复远比事后自动校正可靠。

## 如何看散点和残差

先画每个独立对象的散点，按重要组别/批次着色；查非线性、离群和不同方差。离群点可能支配Pearson r或斜率，需查测量与影响，不可为提高r随意删除。重复测量和家系要用相应层级模型；时间序列自相关会使普通独立P不正确。

| 症状 | 可能原因 | 核对方式 |
|---|---|---|
| r高但预测误差仍大 | 变异范围大、尺度不同 | 报RMSE和独立验证 |
| 加一个协变量系数翻转 | 混杂、共线或目标改变 | 看分层图、设计秩与因果角色 |
| 删除一点结果大变 | 高杠杆/影响点 | 预设影响分析并完整报告 |
| Spearman显著Pearson弱 | 非线性单调、极端值 | 看图而不只选较小P |

## 自测与结论边界

**问：r=0.9表示90%变异解释吗？** 答：简单含截距线性回归中R²=r²=0.81，且限于该样本拟合；不是90%。**问：调整组别后斜率1证明x导致y吗？** 答：不证明，人工或观察数据仍需明确生成与因果假设。**问：PCA协变量能消除所有群体混杂吗？** 答：不能，需诊断与敏感性分析，见[群体结构与GWAS有什么关系](https://github.com/SpiralKernel/bioinfo-wiki/wiki/%E7%BE%A4%E4%BD%93%E7%BB%93%E6%9E%84%E4%B8%8EGWAS%E6%9C%89%E4%BB%80%E4%B9%88%E5%85%B3%E7%B3%BB)。
