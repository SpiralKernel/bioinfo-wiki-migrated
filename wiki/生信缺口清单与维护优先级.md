# 生信缺口清单与维护优先级

> 更新：2026-10-26；状态：可用；验证范围：官方文档与方法来源核对；本页专业软件模板未单独执行。

用研究任务和可核验产物安排补写顺序，避免目录完整却缺少实际操作。

## 目前可以接起来的主线

从[测序技术与PCR学习路线](https://github.com/SpiralKernel/bioinfo-wiki/wiki/%E6%B5%8B%E5%BA%8F%E6%8A%80%E6%9C%AF%E4%B8%8EPCR%E5%AD%A6%E4%B9%A0%E8%B7%AF%E7%BA%BF)进入[变异检测分型与提取学习路线](https://github.com/SpiralKernel/bioinfo-wiki/wiki/%E5%8F%98%E5%BC%82%E6%A3%80%E6%B5%8B%E5%88%86%E5%9E%8B%E4%B8%8E%E6%8F%90%E5%8F%96%E5%AD%A6%E4%B9%A0%E8%B7%AF%E7%BA%BF)，再到[变异注释与功能解释学习路线](https://github.com/SpiralKernel/bioinfo-wiki/wiki/%E5%8F%98%E5%BC%82%E6%B3%A8%E9%87%8A%E4%B8%8E%E5%8A%9F%E8%83%BD%E8%A7%A3%E9%87%8A%E5%AD%A6%E4%B9%A0%E8%B7%AF%E7%BA%BF)，最后衔接GWAS、GS和群体分析。新手先完成一个小闭环：说清输入是什么，运行一次，核对预期，解释一个反例，再换数据。

已有页面的“可用”表示可以阅读，不等于其中每种软件都经过实测。应以每篇验证范围和维护记录为准。

## 后续缺口与交付标准

| 优先级 | 仍需完善的工作 | 怎样才算完成一轮 |
|---|---|---|
| P1 | 真实RNA-seq的FASTQ上游与多方法比较 | 固定原始reads、剪接比对/定量、计数检查；edgeR/voom等另行实测 |
| P1 | 专业SV/CNV/STR/TE检测 | 从原始或已比对reads调用，记录事件匹配、可调用区间与错误，不止提取人工字段 |
| P1 | 实际物种注释数据库构建 | 同版本FASTA/GFF/CDS/蛋白、序列验证、ID映射和失败处理 |
| P2 | eQTL/sQTL、精细定位与共定位 | 区分LD、共定位与因果，核对等位方向和祖源 |
| P2 | 组装、基因预测与完整性评价 | 真实小样本、污染/重复/倍性检查与多指标报告 |
| P2 | 系统发育和比较基因组 | MAFFT/IQ-TREE等实际运行、模型选择和支持度解释 |
| P2 | 剪接与转录本定量 | 区分基因表达、转录本表达和事件使用比例 |
| P3 | 蛋白组与代谢组原始数据处理 | 从谱图/峰表到鉴定、批次与缺失处理，保留证据链 |
| P3 | 单细胞、多组学与空间组学进阶 | 实际供体层级验证与参数敏感性，而非仅展示整合图 |

这些是任务缺口，部分已有概念或软件页；不能据此说整个主题完全空白。低深度、多倍体、细胞器及泛基因组目前补到选型和边界，尚需对应真实数据实操。

## 每次补写的最小单位

一条主线同时补概念、工具、工作流和失败案例。先写一页可运行案例，再拆出重复出现的关键词；术语页负责解释，操作细节只维护在对应工具页或案例页。

每轮登记新增/修订页面、来源、工具版本、输入校验值、实测结果、未测范围和断链检查。日期更新不能替代内容复核。参见[可复现分析与工作流管理](https://github.com/SpiralKernel/bioinfo-wiki/wiki/%E5%8F%AF%E5%A4%8D%E7%8E%B0%E5%88%86%E6%9E%90%E4%B8%8E%E5%B7%A5%E4%BD%9C%E6%B5%81%E7%AE%A1%E7%90%86)、[日志排错与最小复现](https://github.com/SpiralKernel/bioinfo-wiki/wiki/%E6%97%A5%E5%BF%97%E6%8E%92%E9%94%99%E4%B8%8E%E6%9C%80%E5%B0%8F%E5%A4%8D%E7%8E%B0)。

## 方法深度与教学验证（2026-10-26）

[方法与算法系统学习指南](https://github.com/SpiralKernel/bioinfo-wiki/wiki/%E6%96%B9%E6%B3%95%E4%B8%8E%E7%AE%97%E6%B3%95%E7%B3%BB%E7%BB%9F%E5%AD%A6%E4%B9%A0%E6%8C%87%E5%8D%97)将原有66篇方法逐篇深化，并新增EM、HMM、BWT/FM索引和de Bruijn图；[读懂方法公式的最小数学基础](https://github.com/SpiralKernel/bioinfo-wiki/wiki/%E8%AF%BB%E6%87%82%E6%96%B9%E6%B3%95%E5%85%AC%E5%BC%8F%E7%9A%84%E6%9C%80%E5%B0%8F%E6%95%B0%E5%AD%A6%E5%9F%BA%E7%A1%80)补齐阅读符号的桥接。三套人工算例验证计算步骤与正文数值，原有真实案例继续通过链接承接。下一步应根据学生实际练习反馈，补卡住的前置、参数敏感性和真实数据验证；不因扩写就把尚未运行的专业软件标为完成。
