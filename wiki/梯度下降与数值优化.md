# 梯度下降与数值优化

> 更新：2026-10-26；状态：可用；验证范围：2026-10-26核对原始与官方资料；本页Python微型计算已执行；人工数据不代表专业软件或真实研究性能。

优化把“寻找最好参数”转成最小化目标函数。梯度下降根据局部斜率反方向更新参数，是理解回归、神经网络和部分似然拟合的入口。读完应能手算一次更新、解释学习率过大的后果，并区分数值收敛与科学结论有效。

前置为向量、导数和[似然最大似然与MAP估计](https://github.com/SpiralKernel/bioinfo-wiki/wiki/%E4%BC%BC%E7%84%B6%E6%9C%80%E5%A4%A7%E4%BC%BC%E7%84%B6%E4%B8%8EMAP%E4%BC%B0%E8%AE%A1)。如果尚未学导数，可先把梯度理解为“每个参数朝哪个方向小改会使损失增加最快”。

## 更新公式的每个量

设目标L(β)，第t步参数为βt，梯度∇L表示各参数偏导数，学习率η>0。更新$\beta_{t+1}=\beta_t-\eta\nabla L(\beta_t)$。负号使参数局部朝下降方向；梯度大表示局部变化快，不代表应无限迈大步。

最小二乘常用$L=\|X\beta-y\|^2/(2n)$，梯度$X^T(X\beta-y)/n$。X为n×p设计矩阵，y为长度n观测，β为p个参数。若把损失换成未除n的平方和，梯度和合适学习率也变；不能跨实现直接比较“0.01学习率”。

## 用一维二次函数看稳定区间

L(β)=(β−3)²/2，梯度β−3，从β0=0开始。η=0.5给β1=1.5，再到2.25、2.625，逐步接近3。若η=2.1，误差满足e(t+1)=(1−2.1)e(t)=−1.1e(t)，方向交替且幅度变大，所以损失上升。这个特例要求0<η<2才能收敛；一般多维函数由曲率控制步长，不能照搬2为普适阈值。

> 本页例子在项目根目录的Python中运行；标准库例子无需安装包，含NumPy/SciPy的例子先按[R包Python包与可复现环境](https://github.com/SpiralKernel/bioinfo-wiki/wiki/R%E5%8C%85Python%E5%8C%85%E4%B8%8E%E5%8F%AF%E5%A4%8D%E7%8E%B0%E7%8E%AF%E5%A2%83)建立项目环境。Windows命令使用`python`，macOS/Linux可使用`python3`；代码块可复制进该环境的Python交互会话，或保存为项目根目录下的临时脚本再用该环境解释器运行；不要保存到examples目录或任意外部目录后假定项目导入路径仍相同。除特别说明外，只向屏幕输出，不写文件。

```python
def optimize(step, iterations=12):
    b, losses = 0., []
    for _ in range(iterations):
        losses.append((b-3)**2/2)
        b -= step*(b-3)
    return b, losses
b, good = optimize(.5)
_, bad = optimize(2.1)
print('coefficient', round(b,6))
print('good_loss', round(good[0],6), round(good[-1],6))
print('bad_increases', bad[-1] > bad[0])
assert abs(b-3) < .001
assert all(v<=u for u,v in zip(good,good[1:]))
assert bad[-1] > bad[0]
```

检查点：β约2.999268，良好损失下降，坏步长损失增加。这里损失是在每次更新前记录；最后β对应的是第12次更新后的参数，最后一项loss对应更新前一步，比较时要保持时点一致。

## 真实模型还要处理什么

特征尺度差异大时，等高线狭长，一个学习率需迁就最大曲率，导致某方向收敛很慢。标准化或预条件可改善数值性质，但变换规则仍必须保留。最小二乘的梯度Lipschitz常数为$\|X\|_2^2/n$，项目教学求解器使用其倒数作为保守步长，并与`numpy.linalg.lstsq`核对；见[基础算法可复现练习](https://github.com/SpiralKernel/bioinfo-wiki/wiki/%E5%9F%BA%E7%A1%80%E7%AE%97%E6%B3%95%E5%8F%AF%E5%A4%8D%E7%8E%B0%E7%BB%83%E4%B9%A0)。

批量梯度用全部数据；随机/小批量梯度用部分观测估计，可能更快但损失未必每步下降。动量、Adam、牛顿法、拟牛顿法和坐标下降采用不同信息与内存代价；没有一种算法对所有生信模型最优。接口和约束示例见[SciPy优化指南](https://docs.scipy.org/doc/scipy/tutorial/optimize.html)。

## 停止条件不是一句“收敛了”

至少记录最大迭代数、梯度范数、目标改变量、参数变化及终止原因。目标几乎不变可能因到达最优，也可能因步长太小或数值饱和。非凸问题可能停在局部解；分离的逻辑回归则可能系数不断增大而似然趋于极限。即使优化器返回success，错误输入、混杂和数据泄漏仍然存在。

| 症状 | 优先检查 | 处理 |
|---|---|---|
| loss爆炸或NaN | 学习率、溢出、缺失 | 降步长，使用稳定log计算 |
| 很慢但单调下降 | 特征尺度、条件数 | 缩放、预条件或专用求解器 |
| 不同起点结果不同 | 非凸、参数不可识别 | 多起点，比较目标与预测 |
| 达到最大步数 | 梯度/目标是否仍变化 | 报告未收敛，勿只保存最后系数 |

## 自测

**问：训练损失越低预测越好吗？** 答：不一定，过拟合可降低训练损失；独立验证回答泛化问题。**问：乘常数后的损失是否有相同最优点？** 答：正倍数下通常相同，但梯度尺度、停止阈值和学习率都随之改变。**问：把有限差分与解析梯度比较有什么用？** 答：在小输入上帮助发现符号或维度错误，不能替代全部数值与统计验证。
